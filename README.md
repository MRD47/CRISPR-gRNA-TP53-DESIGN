# PROJECT TITLE- CRISPR-gRNA-TP53-DESIGN
CRISPR guide RNA (gRNA) design for TP53 genes using Cas9, Cas12a, Cas12b systems.
This project focuses on computational design and validation of CRISPR guide RNAs (gRNAs) targeting TP53 genes using Cas9,Cas12a and cas12b systems.
# OBJECTIVE
1. Design high-efficiency CRISPR guides
2. Minimize off-target effects
3. Compare Cas9,Cas12a and CAS12b systems
4. Create validated candidate guides for TP53 GENE
# Workflow
1. Retrieve FASTA sequences from NCBI
2. Identify PAM sites in snapgene
3. Design gRNAs using CHOPCHOP
4. Evaluate GC content and self-complementarity
5. Select high-efficiency guides
# TOOLS USED
1. NCBI - Sequence retrieval
2. SnapGene Viewer - Sequence inspection
3. CHOPCHOP - gRNA design
# PIPELINE
1. Target Sequence input
2. gRNA design
3. Scoring & filtering
4. Final candidate selection
# Guide Selection Criteria
1. Efficiency = >70%
2. GC Content = 40–60% 
3. MM0 = 0 
4. MM1 = 0
5. MM2 = 0
6. MM3 = 0-1
7. Self-complementarity = Low 
# Results
The designed guides showed:
- acceptable GC content %
- low self-complementarity
- moderate-to-high efficiency
